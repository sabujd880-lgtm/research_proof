## 2. Task 1 — Manuscript File Upload & Automatic Processing

### Implementation Details
- **Backend API Endpoint**: `POST /api/textguard/import-paper`
  - **Authentication**: `requireAuth` JWT validation middleware.
  - **Payload Validation**: `multer` memory storage with 25MB payload limit. Rejects oversized files with HTTP 413 and unsupported extensions (`.exe`, `.png`, etc.) with HTTP 400.
  - **Extraction Pipeline**:
    - **DOCX**: Utilizes `importDocxFromBuffer` (`mammoth`) extracting headings, titles, and paragraphs.
    - **PDF**: Utilizes `extractPagesFromPdf` parsing PDF streams into page-by-page structures, joining paragraphs with preserved linebreaks.
    - **TXT/MD**: Decodes UTF-8 buffers, extracts manuscript title from leading lines, and calculates paragraph breaks (`/\n\s*\n/`).
  - **Bot Challenge Protection**: Detects and rejects Cloudflare bot challenge text (`Performing security verification`) before analysis.
  - **Document Isolation**: The endpoint returns `{ success: true, filename, fileSize, fileType, title, text, wordCount, characterCount, paragraphCount }` without persisting to the user's `Document` collection, guaranteeing active documents are not silently overwritten.
- **Frontend Studio UI Integration (`client/src/App.tsx`)**:
  - Added full upload lifecycle state machine: `'idle' | 'uploading' | 'processing' | 'success' | 'error'`.
  - Progress tracking via `XMLHttpRequest` upload progress events, driving an interactive progress pill (`Uploading 65%` → `Processing text...`).
  - File pill component displaying imported filename, humanized file size (`KB`/`MB`), 1-click **Replace** button (re-opens file picker), and **Remove** button (clears imported file association).
  - Synchronizes extracted text directly into the Manuscript Inspector textarea, updating word and character counters in real-time.
  - Displays manuscript title badge in the inspector header (`FileCheck2` badge with size).
  - Immediately enables the **Deep Scan** action button upon successful extraction.

## 4. Task 3 — Reference Verification Card Overflow Repair

### Root Cause Analysis & Resolution
- **Root Cause**: The `.tg-metrics-grid` was previously constrained to fixed `repeat(4, 1fr)` without `min-width: 0` on child items. Flex items with non-wrapping titles and action links caused the card to overflow its column boundary on screens between 1080px and 1280px.
- **CSS Grid & Card Layout Fixes (`client/src/styles.css`)**:
  - Changed `.tg-metrics-grid` to `grid-template-columns: repeat(auto-fit, minmax(210px, 1fr))` with `gap: 12px`.
  - Added `min-width: 0; overflow: hidden; height: 100%; box-sizing: border-box;` to `.tg-metric-card`.
  - Enabled flex wrapping and word-breaking in `.tg-metric-header` and `.tg-metric-footer`:
    ```css
    .tg-metric-footer {
      display: flex;
      align-items: center;
      justify-content: space-between;
      gap: 6px;
      margin-top: 4px;
      font-size: 10.5px;
      color: var(--muted);
      flex-wrap: wrap;
      word-break: break-word;
      min-width: 0;
    }
    .tg-metric-footer > span {
      min-width: 0;
      word-break: break-word;
    }
    .tg-metric-action-link {
      white-space: nowrap;
      flex-shrink: 0;
    }
    ```
- **State & Copy Normalization**:
  - **Card Title**: Normalized to `"Reference Verification"`.
  - **Zero/Empty State**: Badge renders `"0 DOIs"`, Value renders `"0"` with unit `"DOIs"`, Footer renders `"No DOI references detected"`.
  - **Populated State**: Badge renders `"${doiVerified}/${doiTotal} Valid"`, Value renders `"${doiVerified}/${doiTotal}"` with unit `"verified"`, Footer renders `"${doiTotal} scholarly items"`.
  - **Action Button**: `"View References →"` with pointer cursor, triggering tab transition to `activeDetailTab = 'doi'`.

## 5. Task 4 — Compact Enterprise Dashboard Profile

### Sizing and Architecture
The sidebar user profile component was redesigned according to Linear-inspired enterprise ergonomics:
- **Circular Avatar**: 30px × 30px (`width: 30px; height: 30px; border-radius: 50% !important;`), supporting both custom image avatars (`.avatar-img`) and deterministic initials (`.avatar`).
- **Username**: 12.5px font size, semi-bold (`font-weight: 600`), truncated with `text-overflow: ellipsis`.
- **Email**: 10.5px muted font size (`color: var(--rp-text-muted)`), truncated with `text-overflow: ellipsis`.
- **Row Dimensions**: 48px height (`height: 48px; min-height: 48px; max-height: 52px;`), 10px horizontal padding (`padding: 0 10px;`).
- **Avatar-to-Text Spacing**: Fixed 8px gap (`gap: 8px`).
- **Dropdown Chevron & Popover**:
  - Vertical alignment via `ChevronUp` with 180° rotation transition on toggle.
  - Enterprise popover menu (`.user-menu-dropdown`) containing:
    - User Identity Header (Name and Email)
    - Settings & Preferences action (`Settings2` icon)
    - Sign out action (`LogOut` icon in destructive red hover state)
  - Dismisses automatically on outside click via React ref event listener.
- **Responsive States**:
  - **Expanded Sidebar**: Displays full avatar, name, email, chevron, and menu.
  - **Compact Sidebar (`isCompact`)**: Hides `.user-meta` and `.user-chevron`, centers the 30px circular avatar with `padding: 0`, and positions the dropdown popover neatly to the right.
  - **Mobile (<760px)**: Automatically aligns to compact layout.
