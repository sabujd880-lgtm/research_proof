# Phase 6 — Citation Validation & Anti-Hallucination Framework

## 1. Principles of Academic Grounding

A fundamental vulnerability of large language models in scholarly workflows is hallucination: fabricating plausible-sounding citations, misattributing findings, and referencing nonexistent page numbers or statistics. 

ResearchProof AI 1.0 Phase 6 solves this by enforcing an algorithmic contract: **zero statement may be presented without an verifiable citation tag matching an indexed passage**.

---

## 2. Citation Architecture

### 2.1. Standard Citation Format
Every grounded claim generated by the RAG engine is terminated with an inline citation tag:
```
[Document Title, p. X]
```
Where:
- `Document Title` is the title or sanitized filename of the indexed paper.
- `p. X` is the exact 1-based physical page number in the original PDF.

### 2.2. Provenance Chain
```
1. Document Upload
   └── Ingestion extracts text strictly partitioned by physical page number.
2. Chunk Generation
   └── Every DocumentChunk maintains an immutable `pageNumber` and `textHash`.
3. Hybrid Retrieval
   └── Candidate passages retain their originating `documentId`, `documentTitle`, and `pageNumber`.
4. Answer Synthesis
   └── The generator injects citation tags exclusively derived from the candidate passages.
5. Post-Synthesis Verification
   └── validateMessageCitations() scans the answer:
       • Extracts all [Title, p. X] tags.
       • Validates that each tag corresponds to a chunk in the retrieved context set.
       • If any tag cannot be matched, it is flagged as unsupported.
```

## 3. Verification Algorithm (`validateMessageCitations`)

```javascript
export function validateMessageCitations(content = '', retrievedCitations = []) {
  if (!content) return { valid: true, unverifiedTags: [], unsupportedCount: 0 };

  const tagRegex = /\[([^,]+),\s*p\.\s*(\d+)\]/g;
  let match;
  const foundTags = [];
  while ((match = tagRegex.exec(content)) !== null) {
    foundTags.push({
      fullTag: match[0],
      titlePrefix: match[1].trim(),
      page: parseInt(match[2], 10)
    });
  }

  const unverified = [];
  for (const tag of foundTags) {
    const verified = retrievedCitations.some(c => {
      const pageMatch = (c.page || c.pageNumber) === tag.page;
      return pageMatch;
    });
    if (!verified) unverified.push(tag.fullTag);
  }

  return {
    valid: unverified.length === 0,
    totalCitationsFound: foundTags.length,
    unverifiedTags: unverified,
    unsupportedCount: unverified.length
  };
}
```

## 4. UI Evidence Provenance Inspector
When a researcher interacts with the PDF Research Chat:
1. Every `[Title, p. X]` tag renders as an interactive citation chip.
2. Clicking the chip:
   - Opens the Evidence Provenance Inspector in the right-hand panel.
   - Displays the verbatim passage, page number, and relevance score ($0.0 - 1.0$).
   - Automatically switches the left-hand Document Viewer to the cited page.
   - Highlights the cited text with an evidence marker.
3. Researcher can copy the verbatim quote with provenance or export the paper to the Literature Matrix.
